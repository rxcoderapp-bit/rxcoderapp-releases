## ✨ 核心功能特色

1. **📋 管制藥品收支智慧對帳**
   - 支援各大醫療院所/診所藥品調劑清冊與 TFDA 申報資料快速比對。
   - 自動抓取漏記、差額與調劑日期異常，毫秒級產出對帳清單。

2. **📝 門市管藥智慧登錄簿冊 (官方動態平衡鏈)**
   - 100% 符合衛福部食藥署 (TFDA) 法規格式標準。
   - 內建動態結存平衡防呆計算，自動防範負庫存與日期倒置。
   - 支援「➕ 新增藥品」、「✏️ 修改藥品資訊」、「🗑️ 刪除藥品」一鍵管理。

3. **📱 慢箋領藥簡訊智慧發送 (官方 SMSGO 介接)**
   - 官方「三步驟發送」：① 輸入內容與預覽 ➔ ② 貼入多門號或匯入 Excel ➔ ③ 預約/即時發送。
   - 支援自動帶入變數 `{姓名}`、`{藥局名稱}`、`{調劑日期}`，內建字數與扣點計算器。
   - 正式授權版自動綁定門市藥局招牌，專業形象加分。

4. **☁️ OTA 線上自動無痛升級**
   - 軟體內建「關於系統」➜ 一鍵檢查與熱升級。
   - 自動排除門市既有之 `*.xlsx` 簿冊與設定檔，**升級 100% 不覆蓋現有資料**。

5. **🔒 100% 門市本機離線安全保證 (Zero-Cloud)**
   - 所有病患個資、處方、管制藥品數據皆僅存於門市本機電腦，絕不上傳任何外部雲端。
   - 通過 PyArmor 9+ 高強度動態語法樹混淆防護，發布包經安全稽核無任何專案明文洩漏。

## 🛠️ 快速開始使用

1. 下載壓縮包後，解壓縮至電腦任意資料夾（建議放置於桌面）。
2. 雙擊執行 `RXcoderapp.exe` 或 `RXcoderapp_藥局小幫手.exe`，約 0.5 秒極速秒開。
3. 門市初次開啟享有 **30 天完整全功能免費試用**。
4. 如欲購買正式版，請進入「ℹ️ 關於系統」複製本機專屬機器碼（HWID）提供給製作人施淳豪，取得專屬序號後即可一鍵毫秒級離線永久解鎖。
